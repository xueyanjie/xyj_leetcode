# 两两交换链表中的节点

## 题目
https://leetcode.cn/problems/swap-nodes-in-pairs/solutions/444474/liang-liang-jiao-huan-lian-biao-zhong-de-jie-di-91/?envType=study-plan-v2&envId=top-100-liked

## 解题 
方法一：递归
时间复杂度：O(n)，空间复杂度：O(n)
```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func swapPairs(head *ListNode) *ListNode {
    if head == nil || head.Next == nil {return head}
    next := head.Next 
    tmp := next.Next
    head.Next = swapPairs(tmp)
    next.Next = head 
    return next 
}
```


方法二：迭代 
时间复杂度：O(n)，空间复杂度：O(1)
```go 
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func swapPairs(head *ListNode) *ListNode {
    if head == nil || head.Next == nil {return head}
    newHead := head.Next 
    var fore *ListNode
    last, curr := head, head.Next 
    count := 1
    for curr != nil {
        count++  // 代表curr为第几个节点
        if count % 2 == 0 {
            last.Next, curr.Next = curr.Next, last
            last, curr = curr, last
            if fore != nil {
                fore.Next = last
            }
        }
        fore = last
        last, curr = last.Next, curr.Next
    }
    return newHead
}
```
