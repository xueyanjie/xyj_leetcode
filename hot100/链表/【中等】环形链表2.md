# 环形链表2

## 题目
https://leetcode.cn/problems/linked-list-cycle-ii/?envType=study-plan-v2&envId=top-100-liked

## 解题 
 ### 方法一：哈希表   
 时间复杂度：O(n)
 空间复杂度：O(n)
```go 
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func detectCycle(head *ListNode) *ListNode {
    temp := head 
    dict := map[*ListNode]bool{}
    for temp != nil {
        if _, ok := dict[temp]; ok {
            return temp 
        }
        dict[temp] = true   // 记录
        temp = temp.Next 
    }
    return nil 
}
```

### 方法二：快慢指针
```
核心思想：fast和slow首次相遇时候，fast比slow多整圈，并且fast走的距离是slow的两倍。
假设slow走了a+b步，fast走了a+b+c+b步，并且fast走的距离是slow的两倍，即2(a+b) = a+b+c+b。
所以a=c，即slow和fast相遇时，再从head开始走，和slow一起走，相遇的点就是环的起点。
```
时间复杂度：O(n)
空间复杂度：O(1)
```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func detectCycle(head *ListNode) *ListNode {
    if head == nil || head.Next == nil {return nil}
    fast, slow := head, head
    for fast != nil && fast.Next != nil {
        slow, fast = slow.Next, fast.Next.Next
        // 在环节点相遇
        if slow == fast {
            ptr := head 
            // 没遇到一起则继续循环
            for ptr != slow {
                ptr, slow = ptr.Next, slow.Next
            }
            // ptr和slow重合，找到了环的起点
            return slow 
        } 
    }
    // 没有环
    return nil 
}
```
