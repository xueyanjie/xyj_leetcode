# 搜索插入位置

## 题目
https://leetcode.cn/problems/search-insert-position/?envType=study-plan-v2&envId=top-100-liked

## 解题
方法一：二分查找
时间复杂度：O(logn)，空间复杂度：O(1)
```go
func searchInsert(nums []int, target int) int {
    n := len(nums)
    left, right := 0, n - 1
    ans := n
    for left <= right {
        mid := (right - left) >> 1 + left    // 位运算、加上偏移量
        if target <= nums[mid] {
            ans = mid
            right = mid - 1
        } else {
            left = mid + 1
        }
    }
    return ans
}
```
